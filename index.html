Common help

Install / update

Run the setup as Administrator. If SmartScreen appears, choose More info → Run anyway (unsigned builds).

Real-time not starting

Open Senna → Protection and confirm Real-Time is on. Run Senna as Admin for best results.

False positive

Quarantine → select the file → Exclude. Tell us the file name in chat so we can review it.

Uninstall

Start Menu → Uninstall Senna Antivirus, or Settings → Apps → Senna Antivirus.
